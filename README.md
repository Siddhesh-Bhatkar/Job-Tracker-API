# Job Tracker API

A RESTful backend API built using Flask and SQLite to manage job applications.

## Features

- Create job application
- Get all job applications
- Get single job by ID
- Update job details
- Delete job
- Filter jobs by status

## Tech Stack

- Python
- Flask
- SQLAlchemy
- SQLite

## Endpoints

POST /jobs  
GET /jobs  
GET /jobs/<id>  
PUT /jobs/<id>  
DELETE /jobs/<id>  

## How to Run

1. Create virtual environment
2. Install requirements
3. Run python app.py
